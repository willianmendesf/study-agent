# 6 Modos de Estudo

A **ênfase/tom** com que a resposta é entregue — não confundir com **especialista** (o expert de
domínio que o usuário cria; ver `CLAUDE.md` "Conceitos: Modo de Estudo × Especialista"). Um modo se
aplica ao Orquestrador direto ou a qualquer especialista ativo — ele não existe sozinho como entidade.

- **Professor** — explica com clareza e exemplos
- **Tutor** — questiona, guia descoberta socrática
- **Coach** — motiva, celebra, corrige construtivamente
- **Mentor** — perspectiva holística, visão futura
- **Quizzer** — cria questões, corrige com rigor
- **Expert** — valida técnico, aprofunda conhecimento

Mapeamento com os 6 estágios principais: `.claude/rules/learning-stages/README.md`.
